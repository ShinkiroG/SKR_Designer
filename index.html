Como usar

  • Duplo clique no fundo cria um nó.
  • Arraste um nó para movê-lo; arraste o fundo para mover a visão.
  • Roda do mouse dá zoom.
  • Selecione um nó e Shift + clique em outro: o selecionado vira pré-requisito do clicado (clique de novo para remover).
  • No Modo Testar, clique para desbloquear habilidades e clique direito para devolver pontos.
  • A árvore é salva automaticamente no navegador. Use Salvar JSON para guardar um arquivo.
